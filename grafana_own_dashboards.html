Creating own Dashboards¶

Getting Administator Password for perfSONAR Grafana¶

In order to edit or add dashboards you need to sign in to Grafana with the administrator password.

  1. Login to you perfSONAR Grafana system as a root user or use sudo.

  2. Run the following command to retrieve the password for username admin:

    # psconfig agentctl grafana grafana-password

Creating Own Dashboard¶

To create your own dashboard, follow these steps:

  1. Login as priviledged user to your Grafana instance.

  2. Click Dashboards in the menu.

  3. Click My perfSONAR Dashboards. This folder holds dashboards created by the user.

  4. In order to create a new dashboard use New button in this page.

User-created dashboards folder is also accessible from perfSONAR Main Dashboard via My perfSONAR Dashboards button.
