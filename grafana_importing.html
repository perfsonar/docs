Importing Dashboards into Existing Grafana¶

You can use existing Grafana instance to visualize your measurements data from perfSONAR archive. You can either import perfSONAR dashboard templates into such Grafana and use them to extend your visualizations or tell local pSConfig agent to set-up additional dashboards and data sources in a remote existing Grafana server.

Importing Dashboard Templates into Existing Grafana¶

You can import preconfigured perfSONAR dashboards into your own Grafana instance from perfSONAR repository. perfSONAR provides a few default dashboards with visualizations of your data:

  • perfSONAR Endpoint Pair Explorer - enables browsing perfSONAR test results between selected source and destination measurement hosts. The metrics include: throughput, latency, packet loss, jiter, rtt, traceroute hop count and unique results. Test results are presented in both directions.

  • perfSONAR Host Metrics - presents overview of selected measurement host status. This includes the history of perfSONAR services status, basic host hardware and software information and settings, CPU, RAM and disk utilization, pScheduler and pSConfig metrics.

Note

Importing perfSONAR dashboards into existing Grafana may require additional dashboard’s confguration to tailor it to your local environment.

Download perfSONAR Dashboard¶

  1. Open the following perfSONAR repository in your web browser:

    https://github.com/perfsonar/grafana/tree/master/perfsonar-grafana/perfsonar-grafana/dashboards/toolkit

  2. Within the browser, click the selected JSON file.

  3. On the selected JSON file view page, right-click the Raw button in the upper right-hand corner and click Save Link as… which should allow you to save the .json file on your local machine.

Import a Dashboard¶

To import a dashboard, follow these steps:

  1. Login as priviledged user to your Grafana instance.

  2. Click Dashboards in the menu.

  3. Click New and select Import in the drop-down menu.

  4. Perform one of the following steps:

    • Upload a previously downloaded dashboard JSON file.

    • Paste dashboard JSON text directly into the JSON model text area.

  5. Change UID, if required.

  6. Click Load.

Setting-up perfSONAR Dashboards in Existing Remote Grafana¶

You can point the psconfig-grafana-agent at an existing Grafana instance to add/modify dashboards on another remote Grafana instance. The pSConfig Grafana agent will connect to remote host and modify its Grafana instance with perfSONAR dashboards, similarly to the local instance.

In the Remote Grafana Server¶

  1. Log in to the remote Grafana as a user with admin rights and create a Grafana service account following Grafana documentation https://grafana.com/docs/grafana/latest/administration/service-accounts/. Assign Admin role to your new service account.

  2. Add a token to this service account.

  3. Copy the generated token.

Note

For more information about creating service accounts contact the remote Grafana instance administrator.

In the Local Archive and pSConfig Server¶

  1. Use the previously created token and set it in your local pSConfig so that it can modify remote Grafana desahboards:

    # psconfig agentctl grafana grafana-token <service-account-token>

  2. Point the local psconfig-grafana-agent at a remote Grafana instance where dashboards and datasources will be built based on the local pSConfig:

    # psconfig agentctl grafana grafana-url <remote-grafana-url>
